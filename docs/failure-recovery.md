# 阶段失败诊断与恢复

诊断按 task/stage/run/generation 保存；Propose 快照独立保存。失败诊断不等于完整日志，证据缺失时必须显示不可用，不能推断文件缺失。老运行可能只有原 error 字段。

## 恢复

用户从当前阶段诊断选择恢复，API 校验诊断关联、任务版本、最新运行、未答问题、会话和安全边界。恢复保持原工作区和阶段；未确认工具结果或会话缺失必须人工检查，不提供自动重放豁免。恢复成功后关联解决旧诊断，失败保留历史。

## 发布与回退

先发布兼容 API/数据库迁移，再发布 Agent/Gateway 和 Web。增量表不得在回退时删除。`RECOVERY_ENABLED=false` 禁止创建新的恢复运行，诊断读取与既有运行继续保留。先关闭新恢复，等待已创建运行结束或由用户停止，再切回兼容镜像。保留 PostgreSQL/workspaces/sessions 卷；不得 down -v。

## 验收证据

当前单元/API 测试覆盖源分类、凭据脱敏、部分快照、路径逃逸、幂等恢复、过期版本及人工检查拦截。容器测试覆盖失败后上传诊断及部分规划产物。完整同抽屉配置往返和真实 Gateway 动态容器恢复/回退演练仍需验收；本文不是这些任务的完成证明。

## 当前实施边界

诊断读取、Propose 快照、条件省略记录和安全恢复 API 已接入；部署前仍需执行真实上游错误注入、配置子视图往返和回滚演练。
