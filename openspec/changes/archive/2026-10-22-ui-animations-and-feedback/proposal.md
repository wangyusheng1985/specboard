## Why

Specboard 目前已完成基础可用版本，核心多阶段状态机与数据同步运行稳定。然而当前界面的视觉语言偏平淡，状态指示均为静态文本徽标，缺乏任务正在后台计算运行的“生命力”感知；各种操作反馈与错误提示依赖顶部红字或静态卡片，易打断心流且缺乏现代专业开发工具（如 Linear、GitLab）的细腻物理触感。

为了将 Specboard 提升为具备高品质交互体验、视觉专业、反馈及时且克制优雅的研发协同工作台，需要按照最终成品效果完整设计并实现 UI 展示效果及交互动画体系。

## What Changes

本变更为系统引入统一的 UI 视觉展示与交互反馈体系，按最终效果完整交付：

- **矢量 SVG 图标体系**：全面替换原有的 Emoji（垃圾桶、外链、关闭等），统一采用 Phosphor/Heroicons 风格的内联矢量 SVG 图标，支持主题自适应与交互微动效。
- **任务状态生命力动效（Liveness & Pulse）**：
  - 执行中（`running`/`recovering`）任务卡片增加呼吸指示灯（Pulse Dot）与环境流光边框；
  - 待回答（`awaiting_answers`/`waiting_input`）增加琥珀橙微光提示；
  - 交付完成（`delivered`）增加翡翠绿成功徽标与微弹动。
- **看板拖拽与垃圾桶物理交互（Tactile Drag & Drop）**：
  - 卡片拖拽时增加轻微物理倾斜与悬浮投影；
  - 放置目标泳道增加平滑呼吸虚线边框；
  - 垃圾桶放置区在拖拽经过时实现盖子弹开微旋、背景危险红晕警示。
- **阶段流程步骤条（Stage Flow Stepper）**：
  - 步骤间增加流动连线与进度感知；
  - 当前进行中步骤序号引入向外扩散的声呐波纹（Sonar Ripple）；
  - 切换查看历史阶段时内容区平滑淡入（Cross-fade）。
- **浮动通知系统（Toast Notification System）**：
  - 替代原静态文本 notice，提供顶部中置浮动 Toast；
  - 区分 Success（对勾）、Error（叹号+轻微震颤）、Info（信息圆圈）；
  - 具备 3.5s 自动滑出退场，支持鼠标悬停时暂停计时。
- **表单与输入微交互（Form Micro-interactions）**：
  - 输入框校验失败时触发轻微水平震颤与红色光晕；
  - 错误提示文本平滑展开下落显示；
  - 问答澄清中的“草稿已保存”采用状态胶囊渐变与绿点脉冲闪烁。
- **操作反馈与微动效（Action Feedback）**：
  - 异步提交按钮在处理中时平滑淡入微型 Spinner，避免误触与假死感；
  - 诊断信息复制按钮支持对勾变换与绿色弹动反馈；
  - 抽屉滑入滑出采用自然的平滑减速贝塞尔曲线。
- **无障碍与动效安全**：全面适配 `prefers-reduced-motion: reduce`，非必要装饰性动画在开启降级模式时完全抑制或降为瞬间切换。

## Capabilities

### New Capabilities
- `ui-interaction-and-feedback`: 为 Specboard 界面提供完整的视觉状态呈现、矢量图标、拖拽交互动效、阶段流转指示与非侵入式 Toast/表单错误提示体系。

## Impact

- **前端视觉与交互代码**：
  - `public/index.html`：更新垃圾桶与辅助图标的结构，引入浮动 Toast 容器。
  - `public/style.css`：新增呼吸灯、流光、Toast、表单震颤、步骤条声呐、拖拽悬停与无障碍减速动效样式。
  - `public/app.js`：重构 `notice` 为现代化 Toast 驱动函数；为表单提交添加异步 loading spinner；为草稿保存与复制按钮添加状态反馈；为任务卡片和步骤条动态赋予运行态类名。
- **外部 API 与服务端状态机**：无破坏性变更（纯前端感知与微交互提升，不破坏原有 API 契约和数据结构）。
