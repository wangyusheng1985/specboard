## Context

详见 `proposal.md`。当前任务详情头部通过 `.detail-drawer-head` 和嵌套的 `.detail-title-card` 组织，垂直占用高度超 160px。在 88vh 的 Bottom Sheet 大画布中，首屏约 25% 的有效高度被头部占用。此外，任务短 ID 被孤立放置在卡片角标中，无法交互，团队成员无法一键复制当前任务的直达 URL 进行分享与协作。

## Goals / Non-Goals

**Goals:**
- 将详情头部垂直高度压缩至约 80px，为下方实际业务内容（产物卡片、成果区、澄清区）释放约 80px~100px 纵向展示空间。
- 采用 UI Skill 推荐的紧凑型层级（Compact Typography Hierarchy）：精修标题字号（14.5px，600 字重，行高 1.45），采用 2 行省略保护，支持悬停查看完整标题。
- 将任务短 ID 重构为可点击的交互式芯片（`.task-id-chip`），集成在顶栏元信息组中，点击即可将直达链接（`https://host:port/?task=<id>&stage=<stage>`）复制到剪贴板，并提供 2 秒的内联视觉反馈与全局 Toast。

**Non-Goals:**
- 不删除或改变现有的停止执行与阶段推进按钮的功能契约。
- 不修改底层 API 或数据表结构。

## Decisions

### 1. 结构优化：去除嵌套厚重卡片，合并为通栏紧凑头部
- **决策**：移除 `.detail-title-card` 的外层卡片阴影、大边距与额外的“任务目标”自言自语小标题栏。改为：
  - 第一行：`[仓库芯片] [任务ID复制芯片] [状态Badge]` 与 右侧 `[停止按钮] [推进按钮] [关闭按钮]` 齐平排列。
  - 第二行：紧凑的语义化标题行，带有左侧细腻 Accent 强调竖线（2.5px），标题文本采用 `-webkit-line-clamp: 2`，超出两行末尾以省略号截断，并绑定完整 `title` 属性。
- **效果**：头部外边距由 22px 28px 18px 压缩至 14px 24px 12px，垂直高度从 160px+ 骤降至 78px~82px。

### 2. 交互式短 ID 芯片设计（Shareable Task Chip）
- **视觉**：采用等宽字体（monospace）、细边框、浅灰色背景与剪贴板 SVG 图标（`#7673c2cb 📋`）。
- **交互**：
  - 点击时优先调用 `navigator.clipboard.writeText(shareUrl)`；若环境不支持则降级为复制纯 ID 或选中文本复制；
  - 触发内联反馈：复制图标与文字瞬时替换为翠绿对勾及“已复制”，2 秒后自动还原；
  - 调用全局 `notice('已复制任务直达链接到剪贴板')`。

## Risks / Trade-offs

- **[风险] 标题被两行截断后可能无法立即看到全部描述** → **[缓解措施]** 设置标准 HTML `title` 属性，鼠标悬停时可即时浮现完整需求文本；且用户创建任务的原始描述在下方各卡片及历史记录中均有完整留存。
