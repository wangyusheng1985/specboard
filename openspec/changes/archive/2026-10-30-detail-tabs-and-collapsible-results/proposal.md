## Why

当前任务详情页将所有模块（基本信息、产物预览、阶段执行报告、用户交互与评论）垂直平铺在同一个长滚动流中。随着任务经历多阶段推演，阶段执行产出的 Markdown 报告越来越长，用户在同一页面中需要费力滚动数十屏才能找到想要查看的阶段结果或评论表单，视觉负担重且缺乏清晰的信息分流。

为了给用户提供现代清晰的视听层级与自如的信息穿梭体验，需要将任务详情主体重构为 3 个功能专注的顶层 Tab（“基本信息”、“阶段成果”、“需求互动与补充反馈”），并为“阶段成果”中多个阶段的 Markdown 渲染卡片提供“默认折叠约 5 行 + 底部虚影渐变 + 一键展开/收起”的折叠卡片机制。

## What Changes

- **任务详情三级 Tab 选项卡架构（Three-Tier Navigation Tabs）**：
  - **Tab 1: 基本信息（默认选中）**：聚焦任务核心全景（所属项目、代码仓库与默认分支、当前阶段与状态、任务完整需求描述、阶段过程产物微缩略图/预览，以及可能存在的未决澄清或失败诊断）；
  - **Tab 2: 阶段成果**：分多个卡片展示任务历经各阶段（Explore, Propose, Apply, MR 等）的执行成果与交付物；
  - **Tab 3: 需求互动与补充反馈**：独立呈现历史用户互动留言时间线与底部指令输入框，随时与 Agent 进行对话；
- **阶段成果多卡片折叠与渐变虚影（Collapsible Markdown Cards with Gradient Fade）**：
  - 阶段成果 Tab 中每个阶段的 Markdown 执行报告卡片**默认处于折叠状态**；
  - 折叠态限制高度在约 5 行内容高度（约 120px~140px），并在卡片底部应用自下而上的平滑白色遮罩渐变虚影，营造“未完待续”的层次感；
  - 卡片底部居中提供精致的“展开详情 / 收起”微交互切换按钮，点击即以流畅的贝塞尔过渡展开完整长文，支持自由收起。

## Capabilities

### Modified Capabilities
- `ui-interaction-and-feedback`: 在任务详情弹窗中重构引入 3 个专职 Tab 选项卡（基本信息、阶段成果、需求互动），并在阶段成果 Tab 中支持多阶段卡片默认折叠（5 行渐变虚影）与一键展开收起。

## Impact

- 页面结构：`public/index.html`（添加 Tab 导航容器与 3 个视图面板）
- 交互状态机：`public/app.js`（Tab 切换、折叠状态维护与卡片按需渲染）
- 界面样式：`public/style.css`（Tab 选项卡美化、卡片折叠高度、底部渐变虚影遮罩）
- 自动化单测与质量门禁：保持 100% 通过。
