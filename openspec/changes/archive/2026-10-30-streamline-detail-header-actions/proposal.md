## Why

在 Specboard 研发看板中，任务所处的阶段（Explore, Propose, Apply, MR, Archive）在全局 5 泳道列表中一目了然，不需要在打开任务详情弹窗后再单独占据一个大卡片（“阶段流程”）进行重复展示。同时，原有的“任务操作”卡片占据了大量垂直空间，导致关键的任务成果、提问与交互信息被推到屏幕下方。

基于现代专业 SaaS（Linear / GitHub Projects / Raycast）界面规范，去除冗余的阶段步骤条与独立操作卡片，将核心控制抽象为头部常驻的 2 个高感知 SVG 语义操作按钮（“停止/暂停”与“推进/主动作”），大幅释放纵向黄金阅读空间，让用户打开详情时直达核心成果。

## What Changes

- **移除任务详情中的冗余大卡片**：
  - 彻底移除 `#stage-tabs` 所在的“阶段流程”大卡片（`.stage-flow`）；
  - 彻底移除 `.task-toolbar` 所在的“任务操作”独立大卡片；
  - 任务当前阶段与状态精简收拢至详情头部作为紧凑语义 Badge 展示（如 `Explore · 等待回答`）。
- **头部操作栏（Header Actions）集成双 SVG 语义按钮**：
  - 在 `.drawer-head` 顶栏右上角（紧邻关闭按钮 `×` 左侧）构建精致的 `.detail-head-actions` 交互操作组；
  - **按钮 1：停止 / 取消 (Stop Button)**：
    - 采用方形/停止矢量 SVG 图标，危险色交互反馈（仅在任务处于运行中或等待输入时激活）；
    - 支持智能悬停 Tooltip 与无障碍标签。
  - **按钮 2：推进 / 确认 / 重试 (Primary Action Button)**：
    - 动态根据任务状态展示自适应的 SVG 图标与紧凑文案（如 Explore 推进下一阶段、Propose 确认方案、运行中停止并归档、受阻时重试当前阶段）；
    - 采用高对比度品牌主色（Primary）样式，集成矢量推进箭头、执行对勾或重试旋转 SVG。
- **视觉层级与纵向阅读体验极大释放**：
  - 任务详情头部紧凑化，关键的过程产物、待澄清提问与执行记录上移超过 220px，打开弹窗即见实质内容。
